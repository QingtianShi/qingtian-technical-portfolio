# SAH EEG Monitoring and Alert System

This project proposes a healthcare information system that supports continuous EEG monitoring and alerting for patients at risk of vasospasm after subarachnoid hemorrhage.

## Deliverables
- Logical ERD
- Physical ERD
- Logical and physical DFDs
- CRUD matrix
- Buy-vs-build analysis
- System architecture
- Interface mockups
- Non-functional requirements

Focused on neurologist and EEG technician workflows, EEG readings, assignments, clinical alerts, and system architecture.
